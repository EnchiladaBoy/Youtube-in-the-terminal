# Youtube in the Terminal

A Python-based application that brings YouTube functionality to your terminal, allowing you to search, browse, and interact with YouTube content directly from the command line.

## Features

- Search YouTube videos directly from your terminal
- View video information and metadata
- Stream video content without leaving your command line
- Lightweight and easy to use

## Installation

1. Clone the repository:
```bash
git clone https://github.com/EnchiladaBoy/Youtube-in-the-terminal.git
cd Youtube-in-the-terminal
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the main application:
```bash
python main.py
```

Follow the on-screen prompts to search and interact with YouTube content.

## Requirements

- Python 3.6+
- See `requirements.txt` for additional dependencies
